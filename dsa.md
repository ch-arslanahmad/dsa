# Data Structures & Algorithms

- **Data Structures**: Data Structures are basically different type of collections (list) of data.
- **Algorithm**: Algorithm is simply step-by-step flow to do a process.

So, DSA is basically storing & processing data based on their benefits and drawbacks.
- Data Structure - storage of data
- Algorithm - processing of data

Its effectiveness is measured by time and space complexity. We will discuss about it in the future.
